# ЗАРНИЦА: КЛЯТВА — браузерный прототип движка предательства

Играбельный веб-прототип ядра механики **«движок предательства»** из игры
**ЗАРНИЦА: The Oath**. Демо-сценарий **«Три ночи»**: 12 решений, 4 спутника,
≈10 минут. Сделан для быстрой демонстрации питча (рядом с Godot-каркасом M0 —
одни и те же правила, две оболочки).

## Что демонстрирует

| Система | Правило в коде |
|---|---|
| **Журнал памяти** | каждый выбор — запись: тег + валентность −3…+3; записи **не тускнеют и не удаляются** |
| **Формула доверия** | `Δ = валентность × вес_тега × чувствительность` — видна в «Летописи движка» после каждого решения |
| **Лестница предательства** | I Сомнение → II Отчуждение → III Заговор → IV Удар в спину → V Разрыв; пороги доверия 60/40/25/10 |
| **Право слова** | на ступенях III–IV переход **замораживается**: исповедь / ложь / дар проклятым золотом / молчание; 1 раз на ступень; очередь при нескольких заморозках |
| **Катализаторы** | сюжетные узлы («Развилка Клятвы», «Тихий час»), усиливающие сомнение тех, кто уже отошёл от клятвы |
| **Пауза присяги** | боевые приказы: спутник на ступени ≥II может **не выполнить приказ** (порог доверия) |
| **V — только сюжет** | движок никогда не ставит Разрыв сам — только сюжетный force_break |

## Спутники (демо)

- **Гаврила** — ветеран порубежья: чтит честь и клятву (чувствительность ×0,9)
- **Ходата** — немой следопыт: справедливый делёж (×1,0)
- **Милута** — летописец: правда и память (×1,25 — самый хрупкий)
- **Ратмир** — молодой мечник: смелость и защита слабых (×1,1)

## Запуск

```bash
bun install
bun run dev
# http://localhost:3000
```

Для демонстрации есть **Пульт испытателя** (внизу экрана): обвал доверия сразу
показывает заморозку перехода, Право слова и отказы в приказах.

## Структура

```
src/lib/zarnitsa/types.ts     — типы ядра
src/lib/zarnitsa/data.ts      — спутники, теги, лестница
src/lib/zarnitsa/scenario.ts  — сценарий «Три ночи» (12 событий)
src/lib/zarnitsa/engine.ts    — ядро: память → доверие → лестница → право слова
src/app/page.tsx              — игровой экран
src/components/zarnitsa/      — карточки спутников, право слова, финал
scripts/zarnitsa-web/simulate.ts — симуляционные прогоны + инварианты (bunx tsx)
```

## Экспорт данных

Кнопка «Скачать журнал (JSON)» на финальном экране выгружает полное состояние
(записи памяти, доверие, ступени) — формат совместим по смыслу с data-слоём
Godot-каркаса M0 (`memory_log.gd` + `betrayal_engine.gd`).
