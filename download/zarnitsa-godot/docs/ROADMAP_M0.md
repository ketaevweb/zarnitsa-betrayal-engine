# Дорожная карта M0 (недели 1–6) — статус

Первая треть этапа прототипа из плана v2.0 (36-месячный Гант, глава 10).
Gate M0 по плану: играбельные 30–60 минут, все системы ядра видны игроку,
сборка на Windows/Linux, плейтест 3–5 людьми.

## Недели 1–2 — ЯДРО (выполнено)

- [x] Godot 4.3, каркас автолоадов, правило инъекций, bootstrapper.
- [x] MemoryLog: теги + валентность −3..+3, без затухания, save/load.
- [x] BetrayalEngine: доверие, лестница I–V, личные веса/чувствительность,
      право слова (III–IV, один на уровень), ключевые моменты, force_break.
- [x] TimeSystem: сутки, фазы, Мгла (полная 22:00–05:00, рампы ±3 часа).
- [x] DialogueManager: JSON-диалоги, эффекты (память/доверие/флаги/монеты),
      плейсхолдер {companion}.
- [x] GameState + EventLog («Летопись Милуты»), единый save в user://.
- [x] Хаб-лагерь (3D-заглушки), HUD доверия, диалоговый UI, отладка F1.
- [x] 5 диалогов, 4 профиля спутников, ~40 юнит-проверок (headless).

## Недели 3–4 — ХАБ (ближайшая работа)

- [ ] InteractionSystem: ходьба персонажа (CharacterBody3D), подход к спутнику,
      Area3D-подсказки; Input Map вместо клавиш 1–4.
- [ ] Инвентарь-стаб: котёл проклятых монет, выдача/делёж, счёт в GameState.
- [ ] Визуал суток: реальный туман (Environment fog), тени, палитра Мглы;
      аудио-заглушки (ветер, костёр, шёпот Мглы — freesound CC0).
- [ ] Модельный пакет: 4 спутника + старшина, low-poly (Blender/kenney,
      аутсорс-бриф $300–500 из бюджета v2.0).
- [ ] Энкаунтер Мглы №1: выход за кромку в ночи (правило из GDD).

## Недели 5–6 — ВЕРТИКАЛЬНЫЙ СРЕЗ «Три ночи»

- [ ] Пролог-сценарий: плач у Чёрного брода → ночной дозор → первый ключевой
      момент (3 сцены × ~10 минут, диалоги в JSON).
- [ ] Связка «день → ночь → Мгла → выбор → память»: полный цикл без брони.
- [ ] Главное меню с «Новой игрой», обучение через первые 5 минут (без туториала-стены).
- [ ] Полировка UI (иконки ступеней, портреты-силуэты), титры-заглушка.
- [ ] Экспорт Win/Linux (не забыть `*.json` в фильтрах ресурсов),
      сборка на закрытой itch-странице, плейтест + анкета.

## Gate-критерии выхода из M0

1. 30–60 минут связного геймплея от запуска до титульного момента.
2. Все 4 спутника реагируют на память игрока; минимум один полный проход
   права слова и один ключевой момент с предательством.
3. ~40 юнит-проверок зелёные на CI-скрипте (`godot --headless -s tests/run_tests.gd`).
4. Сборки Win/Linux запускаются на 2 «чужих» машинах.
5. Анкеты плейтестов: понятны ли ступени лестницы и право слова (цель ≥ 4/5).
