# Движок предательства — реализация M0

Соответствие плану v2.0 (глава «Движок предательства»). Всё описанное здесь
работает в коде и закреплено юнит-тестами (`tests/test_suite.gd`).

## Лестница предательства

Доверие — число 0..100. Уровень L наступает, когда доверие **ниже порога**.

| Уровень | Название | Доверие | Право слова |
|---|---|---|---|
| 0 | Верность | ≥ 60 | — |
| I | Сомнение | 40–59 | — |
| II | Отчуждение | 25–39 | — |
| III | Ультиматум | 10–24 | обязателен |
| IV | Предательство | 0–9 | обязателен (1 раз на уровень) |
| V | Разрыв | только сюжет | нет |

- Уровни I–II применяются сразу; улучшение отношений — тоже сразу.
- Уровень V недостижим очками: `_try_transition` жмёт максимум на IV.
  Разрыв — только `force_break()` (сюжет или ключевой момент).
- Пороги: константы `T_DOUBT / T_ALIENATION / T_ULTIMATUM / T_BETRAYAL`.

## Память (правило «память не тускнеет»)

Запись: тег, валентность −3..+3, источник, цель, сцена, день,
флаг `irreversible`. Записи никогда не удаляются и не ослабляются —
тест `memory_no_decay` фиксирует это на промежутке в игровые сутки.

Расчёт дельты доверия:

```
delta = valence × tag_weight(цель, тег) × sensitivity(цель)
irreversible-провал: delta × 2
```

Веса и чувствительность — в `data/companions.json` (личные профили):
Ратмир чувствителен к жадности (×2.5) и предательству (×3.0) при высокой
общей чувствительности 1.3; Ходата стоек (0.8), но жестокость (×2.0) и
клятвопреступление (×3.0) бьют по нему сильнее всего.

## Право слова

```
падение доверия → целевой уровень III–IV?
   да, и право на этот уровень ещё не использовано:
       pending_transitions[cid] = {from, to}
       сигнал speech_right_requested → сцена открывает диалог
       resolve_speech_right(cid, success):
           успех  → доверие = порог+5, ступень −1
           отказ  → переход вступает
   повторный переход на тот же уровень → без права слова
```

Во время ожидания решения `_reevaluate_level` заморожен — новые события
памяти не «проскакивают» мимо права слова. После успеха сцена пишет в
память `mercy +1` (универсальный диалог делает это сам).

## Ключевые моменты (переломные точки)

`evaluate_pivotal_moment(id)` — сюжетный вызов (в срезе — F3):

1. Сортировка живых спутников по доверию по возрастанию.
2. Каждый получает строку-поведение по своей ступени.
3. Если лидер антирейтинга на ступени ≥ IV — он становится **предателем**:
   `force_break()` + удаление из отряда + запись в Летопись.
4. Отчёт `{traitor, rows[]}` издаётся сигналом `pivotal_evaluated`.

Список моментов — `data/pivotal_moments.json` (в M0: «Развилка у Чёрного
брода», «Ночь клятвы»).

## Руководство по тюнингу

- Начинать с валентностей выборов пролога (±1/±2), не трогая веса.
- Право слова должно спасать при 1 ошибке, но не при системной жестокости:
  следи, чтобы 2–3 провала подряд на III не оставляли игроку выхода.
- Целевая кривая среза: к концу пролога 1–2 спутника на I–II, ни одного на
  IV при аккуратной игре; при жадной игре Ратмир доходит до III к ночи 2.
- Изменять пороги пакетно (−5/+5) и прогонять тесты: они проверяют форму
  лестницы, но не баланс — баланс считается плейтестом.
