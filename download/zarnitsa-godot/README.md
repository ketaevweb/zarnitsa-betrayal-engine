# ЗАРНИЦА: КЛЯТВА (The Oath) — вертикальный срез M0

Стартовый Godot-проект по плану разработки **v2.0** (соло + аутсорс, low-poly, ≤$30k).
M0 = первые 6 недель дорожной карты: работающее **ядро «движка предательства»** +
каркас хаба-лагеря. Играбельно: диалоги с четырьмя спутниками реально меняют
доверие, память, ступени лестницы предательства; право слова и ключевые моменты
работают в полном цикле.

## Быстрый старт

1. Установить **Godot 4.3+** (стандартная сборка, без .NET).
2. Import → выбрать папку `zarnitsa-godot` → открыть проект.
3. Запустить `scenes/main/Main.tscn` (F5). Кнопка **«Юнит-тесты»** — проверка ядра.

## Управление (лагерь)

| Клавиша | Действие |
|---|---|
| 1–4 | Говорить со спутником (Гаврила, Ходата, Милута, Ратмир) |
| F1 | Отладочная панель движка предательства |
| F2 | +1 игровой час |
| F3 | Запустить ключевой момент (переломная точка) |
| F4 | Пауза/запуск времени |

## Тесты из консоли

```bash
godot --headless --path . -s tests/run_tests.gd
```

Код возврата 0 = все проверки прошли. Тесты закрепляют правила плана:
память не тускнеет, уровни I–II без права слова, III–IV через право слова,
уровень V — только сюжетом, Мгла 22:00–05:00, эффекты диалогов считаются
как валентность × вес тега × чувствительность.

## Структура

```
autoload/    ядро: game_state, time_system, memory_log, betrayal_engine,
             dialogue_manager, event_log (без ссылок друг на друга — инъекция)
core/        data_loader (JSON), bootstrapper (привязка автолоадов к данным)
scenes/      main (меню), camp (3D-хаб), ui (HUD, диалоги, отладка)
data/        companions.json, memory_tags.json, pivotal_moments.json,
             dialogues/*.json
tests/       run_tests.gd (headless-раннер), test_suite.gd (~40 проверок)
docs/        ARCHITECTURE.md, BETRAYAL_ENGINE.md, ROADMAP_M0.md
```

## Статус M0

Готово (недели 1–2 дорожной карты):
- MemoryLog: записи тег+валентность −3..+3, без затухания, сохранение.
- BetrayalEngine: доверие 0..100, лестница I–V, личные веса/чувствительность,
  право слова (один на уровень), ключевые моменты, сюжетный Разрыв.
- TimeSystem: сутки, фазы, Мгла (22:00–05:00, подъём/спад по 3 часа).
- DialogueManager: JSON-диалоги, эффекты → память/доверие/флаги/монеты.
- GameState + EventLog («Летопись Милуты»), сохранение в user://.
- Хаб-лагерь (3D-заглушки), HUD, отладочная панель, 5 диалогов.

Дальше — см. `docs/ROADMAP_M0.md` (недели 3–6) и план v2.0, глава 10.

## Примечание про экспорт

JSON-файлы Godot не импортирует как ресурсы: при сборке добавьте `*.json`
в Project → Export → Resources → «Filters to export non-resource files».
