# ЗАРНИЦА / Zarnitsa: The Oath

**Тёмное славянское фэнтези-RPG уровня Ведьмак 3 — полный проектный пакет:**
играбельный веб-прототип, дизайн-документ (GDD) на 30+ страниц и питч-деки
для издателя на русском и английском языках.

> *Бог мёртв. Ночь наступает. Ватага помнит.*

## Ключевые особенности дизайна

- **USP — Обет / движок предательства.** У каждого из 6 компаньонов есть скрытая
  мотивация и личный порог доверия; предательство не скриптовано, а вытекает из
  действий игрока и может быть предотвращено.
- **Обетная пауза (Oath Pause)** — гибрид real-time and pause: бой останавливается
  для отдачи приказов, а пауза «стоит» ресурса клятвы.
- **3 финала** прототипа определяются тем, кто остался верен к третьей ночи.
- **Co-op 2–4** в полной версии: ватага делится между игроками, а механика
  предательства работает и между людьми.

## Играбельный прототип («Три ночи»)

Вертикальный срез одного игрового цикла: **Контракт → Лагерь → Ночь** —
три дня и три ночи, 6 компаньонов, реальные триггеры предательства, 3 финала.

```bash
bun install        # или npm install
bun run db:push    # инициализация SQLite (Prisma)
bun run dev        # http://localhost:3000
```

Стек: Next.js 16 · TypeScript · Tailwind CSS 4 · shadcn/ui · Prisma (SQLite).
